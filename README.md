# fMRIPrep Lifespan paper code
This code repo contains the code used to create the figures in the publication "fMRIPrep Lifespan: Extending A Robust Pipeline for Functional MRI Preprocessing to Developmental Neuroimaging". 

The manuscript is currently available on bioRxiv: https://www.biorxiv.org/content/10.1101/2025.05.14.654069v1
